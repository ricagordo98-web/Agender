# Agender Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Agender agenda app described in `docs/superpowers/specs/2026-10-12-agender-design.md`.

**Architecture:** Shared RCL holds domain, data, services and UI; Web and MAUI are thin hosts that supply the DB path. Pointer interactions in JS, state in Blazor.

**Tech Stack:** .NET 10, Blazor, MAUI Blazor Hybrid, EF Core 10 + SQLite, xUnit, FluentAssertions 7.
